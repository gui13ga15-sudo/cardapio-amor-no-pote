# Stock & Schedule Manager

https://github.com/gui13ga15-sudo/cardapio-amornopote.git incluir na área do lojista uma opção onde posso controlar a quantidade de itens que tenho no estoque,  como por exemplo se so tenho 1 torta de nutella e o cliente tentar pedir 2 só irá liberar 1 para comprar e ficar indisponível quando acabar. Outra opção é para controle de horários e dias de funcionamento,  colocamos como segunda feira esta fechado, mas queremos abrir nessa segunda, entao quero uma opção onde posso controlar os dias e horários para abrir e fechar com facilidade
